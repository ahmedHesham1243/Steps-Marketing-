كيف نعمل

  1. نجد الحكاية

    نفهم نشاطك وجمهورك، ونختار الحكاية التي تجعلهم يكملون.

  2. 3 بدايات لكل سكريبت

    الثواني الثلاث الأولى تحسم كل شيء، فنكتب 3 افتتاحيات وأنت تختار.

  3. عيّنة قبل أي شكل جديد

    عيّنة قصيرة أو صور ثابتة قبل التحريك، حتى لا تدفع ثمن شيء لا يشبهك.

  4. الإنتاج

    تصميم وموشن ومونتاج وأنيميشن، بالعربية والإنجليزية.

  5. فحص نهائي ثابت

    الصوت مطابق للنص، ولا كادر أسود، والمقاسات مضبوطة لكل منصة.

  6. تقرير كل أسبوع

    ما الذي نجح، وتغيير واحد للأسبوع القادم.
